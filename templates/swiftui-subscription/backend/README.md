# __DISPLAY_NAME__ backend

Supabase project + edge functions generated by AppFactory from `app.spec.json`
(monetization `subscription`). Deploy and secrets are handled by the `backend_deploy` MCP tool.

| Path | What |
|---|---|
| `backend/CONTRACT.md` | API contract for the iOS app |
| `backend/PRIVACY.md` | What data goes where (privacy policy and App Privacy label inputs) |
| `backend/EVAL.md` | Model accuracy/cost eval: method, results, decision |
| `backend/eval/` | Eval runner, scoring (+ tests); cost per call from fal's `usage.cost` |
| `backend/smoke/smoke.ts` | End-to-end check of the deployed functions (one paid model call) |
| `backend/legal/` | Builds the legal pages from `store/privacy/*.md` (+ tests) and verifies them live |
| `supabase/migrations/` | Schema, RLS, triggers, analytics views (revoke-views rule) |
| `supabase/functions/analyze` | Photo/text → AI result (fal.ai → OpenRouter → model) |
| `supabase/functions/_shared/analysis.ts` | **App-specific**: prompt, JSON schema, normalization |
| `supabase/functions/usage-status` | Tier and remaining quota |
| `supabase/functions/delete-account` | In-app account deletion (cascades every table) |
| `supabase/functions/legal` | Public Privacy / Terms / Support pages (plain text, app languages) |
| `supabase/functions/rc-webhook` | RevenueCat webhook → `revenue_events` (Ad Ops) |
| `supabase/tests/` | Deno tests: handlers with fakes, shared modules, migrations on PGlite (RLS included) |

## Tests

```bash
cd supabase && deno task test     # functions, schema (PGlite), legal build, eval scoring; no paid calls
deno task check && deno task lint
```

## Deploy (normally through `backend_deploy`)

```bash
cd supabase
supabase db push                                            # migrations
supabase functions deploy analyze usage-status delete-account --use-api
supabase functions deploy legal rc-webhook --no-verify-jwt --use-api
supabase config push                                        # [auth]: anonymous sign-ins, Apple, manual linking
```

## Secrets (`backend_deploy` writes them from `app.spec.json` + `~/.appfactory/config.toml`)

| Name | Source | Notes |
|---|---|---|
| `FAL_KEY` | config `fal_key` | never printed or committed |
| `AI_MODEL` / `AI_FALLBACK_MODEL` / `AI_REASONING` / `AI_TIMEOUT_MS` | spec `ai` | empty fallback disables it |
| `FREE_LIFETIME_SCANS` / `FREE_MODES` | spec `usage.free_lifetime_scans` | 0 or 1; free modes default photo |
| `PHOTO_DAILY_LIMIT` / `TEXT_DAILY_LIMIT` | spec `usage.daily_caps` | subscriber, per local calendar day |
| `FREE_ATTEMPT_LIMIT` / `HARD_ATTEMPT_LIMIT` | spec `usage.abuse_limits` | billed calls per rolling 24 h |
| `ENTITLEMENT_GRACE_HOURS` | spec `usage.entitlement_grace_hours` | max entitlement cache age; never beyond the access end |
| `REQUIRE_CONSENT` | spec `consent.health` | 403 `consent_required` until consent |
| `RC_PROJECT_ID` | app outputs (`.appfactory/outputs.json`) | per app, never the global config |
| `RC_SECRET_KEY` | config `rc_secret_key` | if missing, the functions answer 503, never a paywall |
| `RC_WEBHOOK_SECRET` / `APP_SLUG` | generated / spec | rc-webhook |

## Operations

Analytics views (service role / SQL editor only; revoked from `anon` and `authenticated`, UTC days):

| View | Columns |
|---|---|
| `analytics_daily` | `active_users`, `photo_analyses`, `text_analyses`, `free_analyses`, `premium_analyses`, `not_applicable`, `failed_calls`, `paywall_402`, `paywall_402_users`, `daily_cap_429`, `entitlement_503`, `consent_403`, `cost_usd`, `cost_per_active_user_usd` |
| `analytics_free_funnel` | per free-analysis cohort day: `free_users`, `hit_paywall_users`, `subscribed_users` |
| `ai_cost_daily` | calls, ok calls, cost and cost per ok call per day, model and mode |
| `ai_denials_daily` | refused requests per day, reason, mode and tier |

```sql
select * from analytics_daily order by day desc limit 14;
select *, round(hit_paywall_users::numeric / free_users, 3) as paywall_rate,
          round(subscribed_users::numeric / free_users, 3) as conversion
  from analytics_free_funnel order by cohort_day desc;
select * from ai_cost_daily order by day desc;
```
